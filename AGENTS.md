# DCA AI — рабочий сценарий

- Для совместного тестирования открывать DCA AI (http://localhost:3101/app) и https://app.hyperliquid.xyz/trade в том же пользовательском Chrome, в разделённом режиме (Split view).
- Если пара уже открыта, использовать её, не создавать дубликаты и не разрушать раскладку при обновлении приложения.
- Кнопка Hyperliquid должна быть обычной HTTPS-ссылкой: Chrome позволяет открыть её в Split view через контекстное меню. Не обещать автоматическое включение Split view из JavaScript сайта.
- Не включать микрофон автоматически при открытии; пользователь запускает голос кнопкой Start voice.
- Не менять настройки запуска всего браузера без явного запроса. Для восстановления сессии рекомендовать «Ранее открытые вкладки».
- Сделки, подписи и изменения аккаунта на бирже не выполнять в рамках тестирования интерфейса.
