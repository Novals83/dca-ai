# Integration references

Checked 2026-09-12.

- [Hyperliquid info endpoint](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint): allMids, userAbstraction, standard account state, orders and fills.
- [Hyperliquid spot info](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint/spot): spot metadata, balances and token/pair indexing.
- [OpenAI GPT-Live model](https://developers.openai.com/api/docs/models/gpt-live-1).
- [GPT-Live WebRTC](https://developers.openai.com/api/docs/guides/voice-webrtc): POST /v1/live/sessions with session + transport SDP, session.started and session.close.
- [GPT-Live delegation](https://developers.openai.com/api/docs/guides/live-delegation): client delegation metadata and session.commentary.append results.
- [GPT-Live session lifecycle](https://developers.openai.com/api/docs/guides/live-conversations): input/output transcript delta contracts and timestamps.
- [OpenAI function calling](https://developers.openai.com/api/docs/guides/function-calling): Responses tools and function outputs.
- [Next.js package registry](https://www.npmjs.com/package/next): current stable checked before install, pinned to 16.3.5.
